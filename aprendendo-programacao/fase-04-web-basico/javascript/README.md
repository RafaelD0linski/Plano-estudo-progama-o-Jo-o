# JavaScript no navegador

## Exemplo

```html
<button id="botao">Clique</button>
<script>
  document.getElementById("botao").onclick = function() {
    alert("clicou")
  }
</script>
```

## O que praticar

1. **Selecionar elementos** — `getElementById`, `querySelector`.
2. **Eventos** — `onclick`, `onchange` (em inputs).
3. **Alterar conteúdo** — `elemento.textContent = "novo texto"`.
4. **Validação** — Ao enviar formulário, verificar se campos estão preenchidos e exibir mensagem.

Abra o `.html` no navegador para testar.
