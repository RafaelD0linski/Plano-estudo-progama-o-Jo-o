# 📚 Aprendendo Programação

Repositório para acompanhar a evolução no aprendizado de programação.  
**Ferramenta principal:** Node.js + JavaScript  
**Como rodar:** `node arquivo.js`

**[Abrir guia por semanas](guia-semanas/index.html)** — tela com o calendário semanal e o curso do Gustavo Guanabara (YouTube, Algoritmos e Lógica de Programação). Abra o `index.html` no navegador.

## 📅 Rotina de estudo

- **Técnica Pomodoro:** 25 min estudo → 5 min descanso  
- **Meta:** 4 ciclos por dia ≈ 2h por dia  
- **Regra de ouro:** 20% teoria · 80% prática — programar todo dia!
