# Projeto 2 — Lista de tarefas

## Objetivo

- **Adicionar tarefa** — Input + botão; ao clicar, adiciona o texto na lista.
- **Remover tarefa** — Cada item tem um botão (ex: "Remover") que tira o item da lista.
- **Marcar como concluída** — Checkbox ou botão que risca ou muda o estilo do item.

## Sugestão

- Um `<ul>` ou `<div>` para listar as tarefas.
- Cada tarefa pode ser um `<li>` com texto, botão remover e checkbox.
- Use JavaScript para adicionar/remover elementos no DOM e alterar classe (ex: `.concluida { text-decoration: line-through; }`).

Arquivos: `index.html`, `style.css`, `script.js`.
