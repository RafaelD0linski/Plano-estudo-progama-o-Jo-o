# 02 — Condições

## Exercícios

1. **Verificar maior de idade** — Se idade >= 18, exiba "Maior de idade", senão "Menor de idade".
2. **Verificar número positivo** — Se o número for positivo, exiba "Positivo", senão "Negativo ou zero".
3. **Verificar se passou na prova** — Se nota >= 7, exiba "Aprovado", senão "Reprovado".

## Exemplo

```js
let idade = 18
if (idade >= 18) {
  console.log("Maior de idade")
} else {
  console.log("Menor de idade")
}
```

Crie seu arquivo e rode: `node seu-arquivo.js`
