# 03 — Loops

## Exercícios

1. **Imprimir números 1 até 10** — Use `for` para exibir 1, 2, 3 ... 10.
2. **Tabuada** — Escolha um número e exiba a tabuada (ex: 5 x 1 até 5 x 10).
3. **Contagem regressiva** — De 10 até 1, exibindo cada número.

## Exemplo

```js
for (let i = 1; i <= 10; i++) {
  console.log(i)
}
```

Crie seu arquivo e rode: `node seu-arquivo.js`
