# Projeto 1 — Calculadora

## Objetivo

Calculadora com operações básicas: **soma**, **subtração**, **multiplicação** (e divisão, se quiser).

## Sugestão

- Botões: 0–9 e +, −, ×, =
- Um display (por exemplo um `<input readonly>` ou `<div>`) para mostrar o número atual e o resultado.
- Lógica em JavaScript: guardar primeiro número, operação e segundo número; ao clicar em =, calcular e exibir.

Arquivos sugeridos: `index.html`, `style.css`, `script.js`. Abra `index.html` no navegador.
