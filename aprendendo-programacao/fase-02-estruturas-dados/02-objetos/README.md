# 02 — Objetos

## Exemplo

```js
let pessoa = {
  nome: "Carlos",
  idade: 25
}
console.log(pessoa.nome)
```

## Exercícios

1. **Criar cadastro** — Objeto com nome, idade e e-mail. Exiba os dados.
2. **Alterar valores** — Crie um objeto e depois altere uma propriedade.
3. **Mostrar dados** — Função que recebe um objeto pessoa e exibe nome e idade.

Rode: `node seu-arquivo.js`
