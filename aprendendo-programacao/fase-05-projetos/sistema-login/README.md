# Projeto 3 — Sistema de login

## Objetivo

Tela de login (apenas front-end, sem servidor):

- Campos: **usuário** e **senha**.
- Botão **Entrar**.
- **Validação:** não deixar vazio; se preenchido, exibir mensagem de sucesso (ex: "Bem-vindo!"); senão, exibir "Preencha usuário e senha".

## Sugestão

- Formulário com 2 inputs e um botão type="button" (ou type="submit" e `preventDefault` no JS).
- No JavaScript: ao clicar em Entrar, ler os valores; se ambos preenchidos, mostrar mensagem positiva; caso contrário, mostrar aviso.

Arquivos: `index.html`, `style.css`, `script.js`.
