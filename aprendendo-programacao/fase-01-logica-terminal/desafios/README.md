# Desafios — Fase 1

Exercícios que misturam variáveis, condições, loops e funções.

1. **Calculadora simples** — Funções para soma, subtração e multiplicação.
2. **Par ou ímpar** — Função que recebe um número e exibe "Par" ou "Ímpar".
3. **Números de 1 a N** — Função que recebe N e exibe de 1 até N no console.

Crie um arquivo `.js` para cada desafio e rode com `node arquivo.js`.
