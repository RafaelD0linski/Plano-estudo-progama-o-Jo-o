# 10 exercícios de fixação por semana

Cada arquivo tem **10 desafios** com a **solução em código** logo abaixo (em `<details>`).  
Tente fazer o desafio antes de abrir a solução.

| Semana | Arquivo | Tema |
|--------|---------|------|
| 1 | [semana-01.md](semana-01.md) | Variáveis e estrutura sequencial |
| 2 | [semana-02.md](semana-02.md) | Estrutura sequencial |
| 3 | [semana-03.md](semana-03.md) | Condicionais (if/else) |
| 4 | [semana-04.md](semana-04.md) | Loops (for) |
| 5 | [semana-05.md](semana-05.md) | Funções |
| 6 | [semana-06.md](semana-06.md) | Arrays |
| 7 | [semana-07.md](semana-07.md) | Objetos e manipulação de dados |
| 8 | [semana-08.md](semana-08.md) | Algoritmos |
| 9 | [semana-09.md](semana-09.md) | HTML e CSS |
| 10 | [semana-10.md](semana-10.md) | JavaScript no navegador |
| 11+ | [semana-11.md](semana-11.md) | Projetos (calculadora, lista, login, etc.) |

- **Semanas 1–8:** rode os códigos com `node arquivo.js` (crie um `.js` por exercício se quiser).
- **Semanas 9–11:** crie arquivos `.html` (e `.css` se quiser) e abra no navegador.
