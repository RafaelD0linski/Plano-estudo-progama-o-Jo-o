# 01 — Variáveis

## Exercícios

1. **Mostrar nome** — Crie variáveis com seu nome e idade e exiba no console.
2. **Somar números** — Crie duas variáveis com números e exiba a soma.
3. **Converter idade** — Armazene sua idade e exiba "Tenho X anos".

## Exemplo

```js
let nome = "Carlos"
let idade = 20
console.log(nome)
console.log(idade)
```

Crie seu arquivo (ex: `exercicios.js`) e rode: `node exercicios.js`
