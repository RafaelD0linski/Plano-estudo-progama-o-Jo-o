# CSS

## O que praticar

1. **Cores e fontes** — Alterar cor de fundo, cor do texto e fonte da página.
2. **Layout** — Centralizar um bloco, usar `margin` e `padding`.
3. **Responsivo básico** — Usar `max-width` e unidades como `%` ou `rem`.

## Exemplo

```css
body {
  font-family: sans-serif;
  background-color: #f0f0f0;
}
h1 {
  color: #333;
}
```

Crie um arquivo `.css` e ligue no HTML com `<link rel="stylesheet" href="seu-arquivo.css">`.
