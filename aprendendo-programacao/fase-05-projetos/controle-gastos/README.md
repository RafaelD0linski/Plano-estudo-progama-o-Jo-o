# Projeto 4 — Controle de gastos

## Objetivo

- **Campos:** descrição, valor e categoria (ex: Alimentação, Transporte, Lazer).
- **Adicionar gasto** — Botão que adiciona o gasto em uma lista na tela.
- **Listar gastos** — Mostrar descrição, valor e categoria de cada um.
- **Total geral** — Exibir a soma de todos os valores.

## Sugestão

- Formulário: input (descrição), input number (valor), select ou input (categoria).
- Array em JavaScript para guardar os gastos (objetos com descrição, valor, categoria).
- Ao adicionar, dar push no array e atualizar a lista e o total na tela.
- Pode usar uma tabela ou divs para exibir a lista.

Arquivos: `index.html`, `style.css`, `script.js`.
