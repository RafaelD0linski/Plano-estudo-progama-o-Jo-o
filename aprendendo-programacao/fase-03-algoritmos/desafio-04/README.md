# Desafio 04 — Simulação de banco

Simule uma conta bancária no terminal:

- Variáveis: `saldo` (número).
- Funções (ou lógica no próprio código):
  - **Depositar:** adiciona valor ao saldo e exibe novo saldo.
  - **Sacar:** subtrai valor do saldo (só se tiver saldo suficiente) e exibe novo saldo.
  - **Ver saldo:** exibe o saldo atual.

Teste depositando, sacando e exibindo o saldo.

Crie seu arquivo `solucao.js` e rode: `node solucao.js`
