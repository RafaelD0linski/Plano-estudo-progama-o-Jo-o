# 01 — Arrays

## Exemplo

```js
let frutas = ["maçã", "banana", "laranja"]
console.log(frutas[0])
```

## Exercícios

1. **Percorrer lista** — Use `for` ou `for...of` para exibir cada item do array.
2. **Somar números** — Array de números, exiba a soma de todos.
3. **Encontrar maior valor** — Array de números, exiba o maior.

Rode: `node seu-arquivo.js`
