# 03 — Manipulação de dados

Pratique combinar arrays e objetos: listas de pessoas, filtros, etc.

## Exercícios

1. **Lista de pessoas** — Array com 3 objetos (nome, idade). Percorra e exiba cada um.
2. **Buscar por nome** — Array de objetos; função que recebe nome e retorna o objeto (ou null).
3. **Somar propriedade** — Array de objetos com "valor"; exiba a soma de todos os valores.

Rode: `node seu-arquivo.js`
