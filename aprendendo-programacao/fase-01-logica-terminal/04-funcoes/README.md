# 04 — Funções

## Exercícios

1. **Função soma** — Recebe dois números e retorna a soma.
2. **Função calcular média** — Recebe 3 notas e retorna a média.
3. **Função verificar idade** — Recebe idade e retorna "Maior" ou "Menor" de idade.

## Exemplo

```js
function soma(a, b) {
  return a + b
}
console.log(soma(5, 3))
```
