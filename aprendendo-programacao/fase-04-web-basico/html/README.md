# HTML

## Exemplo

```html
<button id="botao">Clique</button>

<script>
  document.getElementById("botao").onclick = function() {
    alert("clicou")
  }
</script>
```

## Exercícios

1. Página com título, parágrafo e um botão.
2. Formulário com campos: nome e e-mail.
3. Lista (ul/li) de 3 itens.

Abra o arquivo `.html` no navegador para testar.
