# Desafios — Fase 2

1. **Agenda** — Array de objetos (nome, telefone). Função para adicionar e outra para listar.
2. **Maior e menor** — Dado um array de números, exiba o maior e o menor.
3. **Média de idades** — Array de pessoas (objetos com idade); calcule e exiba a média.

Crie um arquivo `.js` para cada desafio e rode com `node arquivo.js`.
