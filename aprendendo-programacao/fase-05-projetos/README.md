# 🚀 Fase 5 — Projetos reais

Construir projetos completos com HTML, CSS e JavaScript.

---

## ✅ Checklist da Fase 5

- [ ] **calculadora** — soma, subtração, multiplicação (e divisão se quiser)
- [ ] **lista-tarefas** — adicionar, remover, marcar como concluída
- [ ] **sistema-login** — usuário, senha, validação (front-end)
- [ ] **controle-gastos** — descrição, valor, categoria; listar e somar

Quando terminar cada projeto, marque com ✔ acima.

---

## 📁 Projetos

| Pasta | O que fazer |
|-------|-------------|
| `calculadora` | Botões de números e operações; exibir resultado na tela. |
| `lista-tarefas` | Input + botão para adicionar; lista com opção de remover e marcar concluída. |
| `sistema-login` | Campos usuário e senha; botão "Entrar"; validar (ex: não vazios) e exibir mensagem. |
| `controle-gastos` | Formulário (descrição, valor, categoria); lista de gastos; total geral. |

Cada projeto pode ser uma pasta com `index.html`, `style.css` e `script.js`.
