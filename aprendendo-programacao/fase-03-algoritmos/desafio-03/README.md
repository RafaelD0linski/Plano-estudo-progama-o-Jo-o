# Desafio 03 — Sistema de notas de aluno

Crie um pequeno sistema que:

- Receba (em variáveis) nome do aluno e 3 notas.
- Calcule a média.
- Se média >= 7: "Aprovado"
- Se média >= 5 e < 7: "Recuperação"
- Se média < 5: "Reprovado"

Exiba o nome, a média e a situação.

Crie seu arquivo `solucao.js` e rode: `node solucao.js`
